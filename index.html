DIALOGUE

Protocol-First Programming Language

What is DIALOGUE?

DIALOGUE is a programming language where the fundamental unit of code is a conversation between named participants, we don't mess with functions, classes, or modules.

Example Program

dialogue authenticate(client, auth, db)
  client -> auth : Login(username, password)
  auth   -> db   : Lookup(username)
  db     -> auth : User(hash) | NotFound
  on NotFound:
    auth -> client : Rejected
    end
  auth -> client : Token(jwt) | Rejected

Run It Yourself

python interpreter.py hello_world.dlg
python interpreter.py fizzbuzz.dlg --args n=20
python interpreter.py authenticate.dlg --args username=alice
